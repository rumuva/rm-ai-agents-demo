# RM AI Agents — demostración pública

Demostración estática de **tres páginas**: [Inicio](./index.html), [Creador de asistentes](./dashboard.html) y [Área de empresas y agendas](./cuentas.html).

La agenda permite añadir, modificar, eliminar, filtrar e imprimir **citas ficticias**, con vistas por día, semana y mes. Los datos se guardan **solo en el navegador** mediante almacenamiento local; no se comparten entre dispositivos, no hay reservas reales, ni notificaciones, ni base de datos centralizada.

El creador de asistentes es un simulador de respuestas basado en el texto proporcionado, **no una IA conectada**. La página pública de empresas no admite registro ni inicio de sesión. **No introducir datos personales ni confidenciales.**

Este repositorio contiene exclusivamente archivos estáticos para GitHub Pages. El proyecto original y su backend permanecen privados.
